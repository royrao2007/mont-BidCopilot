## B-20261126-01 · 兼容性评估：DSH 0.2.3-alpha.2

**批次日期**：2026-11-26
**来源**：用户请求「适配到 dsh v0.2.3-alpha.2，兼容现在的版本，看看可行不」
**性质**：**可行性评估批次**，未动任何代码。评估结论见下。

### 本批清单（核对基线）

| 编号 | 问题描述 |
|---|---|
| B2-01 | 本插件能否兼容 DSH 0.2.3-alpha.2？需查清该版本是否有破坏本插件的接口变更 |

### 评估方法与证据

**① 该版本存在于 alpha 通道**

```
npm dist-tags:
  latest = 0.2.2-rc.5    ← 当前运行版本
  next   = 0.2.2-rc.5
  alpha  = 0.2.3-alpha.2  ← 目标版本
```

**② 升级指南：0.2.2-rc.5 → 0.2.3-alpha.2 之间只有一个断点**

下载 `@deepseek-ai/dsh@0.2.3-alpha.2` tarball 并解压，其 `docs/upgrade-guide/README.md` 中，位于 `v0.2.2-rc.5` 之上、覆盖本升级区间的仅 `## v0.2.3-alpha.1` 一节，该节**只有一条变更**：

> Node.js 24.22.3 or 26.13.1 is required

路径：`docs/upgrade-guide/v0.2.3-alpha.1/node-24-22-3/guide.md`。
**没有任何工具 API、Config、Context、事件（Event）或宿主服务（Host Service）的破坏性变更。**

**③ 但依赖库跨了次版本（alpha 通道）**

| 依赖 | 当前运行 | 0.2.3-alpha.2 使用 |
|---|---|---|
| `@deepseek-ai/cordis` | 4.1.0 | **~4.2.0-alpha.1** |
| `@deepseek-ai/schemastery` | 3.19.0 | **~3.20.0-alpha.1** |
| `engines.node` | `>=24.9.0` | **`^24.22.3 \|\| >=26.13.1`** |

虽然升级指南未把它列为本区间破坏项，但这两个是直接依赖的库，**必须实测**而非推断。

**④ 实测：本插件真实入口跑在两个新版库上**

在隔离目录安装 `cordis@4.2.0-alpha.1` + `schemastery@3.20.0-alpha.1`，然后用 `import()` 加载本插件的 `index.js` 与 `lib/tools.js`、`lib/runtime.js`，共 12 项断言：

```
PASS default 导出对象
PASS name 正确
PASS inject 是数组
PASS apply 是函数
PASS Config['~standard'] 存在
PASS 合法输入通过
PASS 已知键保留
PASS 未知键被裁剪（本插件自包逻辑生效）
PASS 结果恰为 5 个已知键
PASS 注册 32 个工具
PASS 14 个写工具带 when 条件
PASS 只读模式下写工具条件全部 false

结果: 完全兼容
```

补充实测：`ctx.provide / ctx.inject / ctx.effect / ctx.get` 在 cordis 4.2.0-alpha.1 下全部存在；`schemastery` 的 `~standard.validate` 行为未变，仍**保留未知键**，因此本插件自包的裁剪层依然必要且仍然生效。

### 本批记录

#### B2-01　DSH 0.2.3-alpha.2 兼容性结论

- **编号**：B2-01
- **发现来源**：用户请求的可行性评估
- **问题描述**：本插件（0.5.0）能否在新版 DSH 0.2.3-alpha.2 下工作
- **根因（评估结论）**：
  1. **代码层完全兼容**：无任何破坏性 API 变更，实测 12 项断言全过。
  2. **唯一的实际障碍是 Node 版本**：0.2.3-alpha.2 要求 `^24.22.3 || >=26.13.1`，本机为 **v24.21.0**，**差 0.1.3 个补丁版本，不达标**。
  3. 本插件当前 `engines.node` 声明为 `>=24.9.0`，对两个版本都满足，**不需要改**。
- **涉及文件与函数**：**无代码变更**（评估批次）
- **验证方式**：
  ```bash
  # 复现兼容性实测
  mkdir /tmp/probe && cd /tmp/probe
  npm init -y && npm i @deepseek-ai/cordis@4.2.0-alpha.1 @deepseek-ai/schemastery@3.20.0-alpha.1
  node -e "import('<repo>/index.js').then(m=>console.log(m.default.name))"
  # 期望：dsh-mont-bidcopilot
  ```
  Node 达标判定：`node --version` 需为 ≥24.22.3 的 24.x 或 ≥26.13.1。
- **日期**：2026-11-26
- **状态**：**不修（无需修复）**

  **不修理由**：本批次是可行性评估，结论是**代码零改动即可兼容**。唯一阻塞项是宿主 Node 运行时版本，属于**部署环境问题，不是插件代码问题**——插件无法也不应该在代码里绕过宿主对 Node 的要求。要真正跑在 0.2.3-alpha.2 上，需升级本机 Node 到 ≥24.22.3，再安装 alpha 通道的 DSH。**该动作超出插件仓库范围，需用户决定。**
